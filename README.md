# SCP-1162

This mod adds gambling in Peanut's spawn, where you can drop any item and get another item. You can do it in Peanut's light OR heavy containment spawn, and of course everything is configurable. This is a re-creation of [SCP-1162 made by xRoier](https://github.com/xRoier/SCP-1162-EXILED) (it was one of the most fun SCP mods ever, so I HAD to keep it going)!!

## Setup

Its a standard installation, no dependencies. Below is the process for any beginners:

1. Download the latest version of `SCP-1162.dll` from the releases page.
2. Place `SCP-1162.dll` into `<SCP_DIRECTORY>/LabAPI/plugins/global/`. SCP_DIRECTORY would be wherever your SCP Secret Laboratory folder is. For example, I get to my SCP_DIRECTORY on Windows by doing %appdata% in File Explorer and then going to the "SCP Secret Laboratory" folder from there.
3. Start/restart SCP: Secret Laboratory Dedicated Server. Feel free to edit any config values at `<SCP_DIRECTORY>/LabAPI/configs/<YOUR_SERVER_PORT>/SCP-1162/`.
